# Publication scope

This repository extracts **GroupAR**, the authored AR/platform prototype, from a larger local Unity experiment folder.

Included: the GroupAR scripts and scene, Unity/XR configuration, API, browser dashboard, processing worker, data contracts and design notes.

Excluded: paid SDKs and their example applications, vendor demo media, Unity caches, IDE/editor integration settings, local logs and build output. The original working project is preserved separately.

Publication maintenance uses Unity 6000.3.19f1 (the source project recorded 6000.3.13f1), updates the worker's vulnerable dependencies, adds repeatable checks, serves the dashboard and fixtures from the local API, and corrects malformed-JSON error handling. These are maintenance changes to the existing prototype; renderer stubs and the mock platform remain explicitly labeled.

## Fixture provenance

The original experiment referenced media from installed vendor examples. Public fixtures are instead generated by `tools/generate-fixtures.py`: original deterministic colored PNG grids and a two-second FFmpeg test pattern. The generator updates manifest sizes and SHA256 hashes. Existing IDs are retained for contract continuity, so names such as `person_video` are legacy IDs and no longer describe a photograph or person.

Quality fields are synthetic warnings with zero placeholder scores. They are not measured ARCore/OpenCV quality results. Checked-in media can be used without running the generator; regeneration requires Python and FFmpeg.

The underlying commercial SDKs are neither bundled nor required for GroupAR's authored AR Foundation code. Optional worker quality tools use external OpenCV/FFmpeg/ARCore tooling, not the excluded Unity asset packages.
